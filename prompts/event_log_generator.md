# Инструмент: event_log_generator

## Описание
Имитатор нагрузки логгера, использующий статистические распределения NumPy RNG для создания реалистичного потока событий. Предназначен для стресс-тестирования систем мониторинга, проверки работы алертов и анализа пропускной способности.

## Математические модели (Сценарии)
При вызове инструмента выбери подходящий `scenario` для имитации конкретного поведения системы:

1. **'normal' (Poisson Process)**:
   - Использyeт экспоненциальное распределение интервалов ($dt \sim \text{Exp}(\lambda)$).
   - **Применение**: Имитация стандартного пользовательского трафика. События независимы, интервалы случайны, но средняя скорость (EPS) стабильна.


2. **'burst' (Traffic Spikes)**:
   - Комбинированная модель: 20% событий имеют интервал `1/(intensity * 5)`, 80% событий — `1/(intensity / 2)`.
   - **Применение**: Проверка систем на выживание при резких скачках нагрузки, DDOS-атаках или каскадных сбоях ("шторм логов").


3. **'sparse' (Background/Idle)**:
   - Равномерное распределение интервалов в диапазоне от 1.5x до 3x от базового.
   - **Применение**: Имитация ночного режима или систем с низкой активностью.

## Параметры
- `intensity` (float): Целевое количество событий в секунду (EPS). Базовый интервал между логами рассчитывается как $1.0 / intensity$.
- `level` (str): Уровень логирования. Влияет на серьезность выводимых сообщений (`info`, `error`, `critical` и т.д.).
- `count` (int): Общее количество итераций. Инструмент автоматически завершит работу после генерации указанного числа логов.

## Инструкция по использованию для LLM
1. Используй этот инструмент, если тебе нужно проверить, как система обработки данных реагирует на высокую нагрузку.
2. Для проверки **алертов на критические ошибки**, сочетай сценарий `burst` и уровень `level='critical'`.
3. Для **нагрузочного тестирования базы данных** устанавливай `intensity` выше 50 и `count` от 1000.
4. Помни: функция блокирующая (использует `time.sleep`), поэтому при больших значениях `count` ответ сервера может занять длительное время.
