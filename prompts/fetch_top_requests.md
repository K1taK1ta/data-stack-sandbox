# Инструмент: fetch_top_requests

## Цель
Получение списка похожих и популярных запросов (Top Requests) из Яндекс.Вордстат. Используется для расширения семантического ядра и поиска смежных ниш.

## Аргументы
- **phrases (list[str])**: Список базовых фраз. Важно: даже одну фразу нужно передавать как элемент списка, например `["ноутбук"]`. Если просят несколько фраз. То должен их в список закинуть, а не вызвать функцию по отдельности.
- **region_name (str)**: Название региона (город, область или страна) в именительном падеже. Например: "Москва", "Казахстан".

## Поведение и логика
1. Инструмент конвертирует `region_name` в технический ID Яндекса.
2. Для каждой фразы запрашиваются похожие запросы и их частотность (impressions) за 30 дней.
3. Данные автоматически сохраняются/обновляются в таблице `related_keywords` (метод UPSERT).
4. Возвращает текстовый отчет о количестве обработанных фраз.

## Когда использовать
- Когда пользователь просит "найти идеи для ключевых слов" или "расширить список запросов".
- Для оценки популярности смежных тематик в конкретном регионе.
