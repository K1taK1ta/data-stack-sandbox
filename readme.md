# 📊 Data Stack Sandbox: Full-Cycle Analytics Pipeline
Репозиторий содержит готовую инфраструктуру "песочницы" для сбора, хранения и визуализации данных. Проект объединяет современные инструменты обработки данных (OLAP/OLTP) и BI-платформы в единую экосистему

Дополнительно инфраструктура поддерживает работу с **локальными языковыми моделями (LLM)** через протокол **MCP**, что позволяет моделям безопасно получать доступ к данным из ClickHouse и PostgreSQL


| Сервис / API           | Адрес                  | Логин / Пароль (default) | Описание                                      |
|-------------------|------------------------|---------------------------|-----------------------------------------------|
| Grafana           | http://localhost:3000  | admin / admin             | Мониторинг и технические дашборды            |
| Metabase          | http://localhost:3001  | Настраивается при входе   | Бизнес-аналитика и визуализация              |
| ClickHouse HTTP   | http://localhost:8123  | default / 123             | Интерфейс для SQL запросов к OLAP            |

## 🚀 Быстрый старт

### 1. Подготовка окружения

Создайте файл `.env` и скопируйте в него переменные из шаблона `.env.example`

⚠️ **Внимание:**
Обязательно отредактируйте файл `.env`, заменив стандартные значения
(ранее захардкоженные в `docker-compose.yml`) на собственные уникальные ключи и пароли.

Пример:

```
POSTGRES_PASSWORD=your_strong_password
CLICKHOUSE_PASSWORD=your_secret_password
```

**Получение токена для Wordstat API**

Для работы с API Яндекс Wordstat необходим **токен** (переменная `token`).

1. Перейдите в документацию Яндекса:
   [Wordstat API](https://yandex.ru/support2/wordstat/ru/content/api-wordstat)

2. Авторизация и токен:
   - Для работы с API требуется **OAuth-токен Яндекса**.
   - Получить его можно через [Яндекс OAuth](https://yandex.ru/dev/id/) — создайте приложение и получите токен для доступа к Wordstat API.

3. Использование в `.env`:

```env
TOKEN=ваш_токен_от_яндекса
```

###  2. Подключение интерфейсов (MCP)

Проект настроен для работы с современными AI-интерфейсами через протокол MCP:

LM Studio и Cherry Studio
Используется для запуска локальных языковых моделей.
MCP-сервер позволяет моделям получать доступ к данным в ClickHouse и PostgreSQL.

Выберите и скачайте подходящую вам языковую модель с поддержкой работы с инструментами (Tool-Enabled).

### 3. Конфигурация MCP (mcp.json)

**Файл mcp.json определяет подключение клиентского интерфейса к MCP-серверу. Пример:**

```json
{
  "mcpServers": {
    "server": {
      "url": "http://127.0.0.1:8000/sse"
    }
  }
}
```

💡 В качестве альтернативы можно использовать:

```"url": "http://localhost:8000/sse"```

Оба варианта работают для локальных подключений, но 127.0.0.1 иногда надёжнее

### 4. Запуск инфраструктуры

Перед первым запуском (или после изменения Dockerfile / зависимостей) выполните сборку образов:

```bash
docker-compose build
```

После этого запустите инфраструктуру в фоновом режиме:

```bash
docker-compose up -d
```
